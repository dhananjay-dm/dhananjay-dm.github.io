## 🌐 Deploying Online (Free & Easy)

### 1. GitHub Pages
1. Create a repository on GitHub (e.g. `dhananjay-portfolio`).
2. Push the files in this folder.
3. In repository **Settings** &rarr; **Pages**, choose the `main` branch root. Your site is live!

### 2. Vercel / Netlify
1. Drag and drop this folder onto [netlify.com/drop](https://app.netlify.com/drop) or import from GitHub on Vercel.
2. It deploys instantly with a free SSL certificate.

### 3. Hostinger Hosting
1. Upload the files inside this directory to your `public_html` directory in Hostinger hPanel File Manager.
